# 我在北京挺好的：三日骑手

一款根据 2017 年 7 月 7 日一篇真实日记改编的纪实视觉小说。手机、电脑自适应，
浏览器直接打开即可游玩，无需服务器、无需联网。

## 运行

双击 `index.html`，或把整个文件夹拖进浏览器。首次通关约 45–60 分钟，进度自动保存。

- 空格 / 回车 / 点击画面：继续
- 「未发生的可能」是黄色标注的假设支线，非史实，看完自动回到真实主线
- 右上角：历史文本 · 章节选择 · 设置（声音 / 音量 / 逐字速度 / 清除存档）
- 通关后在结局页解锁「事实年表」与「原文后记」

## 关于画面

场景在没有插画时，会用与天气/情绪匹配的渐变呈现，游戏依然完整可玩。
若要补上 14–18 张写实电影插画：

    export IMG_TOKEN=<图片生成密钥>
    python3 ../../work/generate-images.py

生成的 WebP 会落到 `assets/images/`，文件名与剧情数据一一对应，无需改代码，
刷新页面即可看到。（密钥只经环境变量传入，不会写进任何交付文件。）

## 声音

雨声、雷声、车流与配乐全部由浏览器 Web Audio 现场合成，无任何外部音频文件、
无版权依赖。默认可选「带声音进入」或「静音进入」。
